# Medium Publish Checklist

## Content Structure
- Ensure one H1 title only.
- Keep section headings consistent (`##` for major sections).
- Flatten accidental nested bullets.
- Keep example callouts as plain text unless list semantics are needed.

## Media Safety
- Upload images in Medium editor (PNG/JPG/WebP preferred).
- Remove local image links that point to filesystem paths or file URIs.
- Avoid SVG image links for article body embeds.
- Add caption text directly below each image.

## Common False Alarm
- Reader promo cards (for app download/membership) are Medium UI inserts, not article formatting bugs.

## Publish Pass
- Re-read in preview mode for spacing and list indentation.
- Confirm code blocks are fenced and monospaced.
- Confirm all five topic slots are used when discovery matters.
